# Muse Session Protocol transcripts (vendored fixtures)

Seven golden transcripts of the Muse Session Protocol (MSP) v1, copied
unchanged from Meta's `meta-models/muse-code-sdk`, directory
`schema/msp/transcripts/<scenario>/transcript.ndjson`, at commit
`07e1548c55c268d2bc91966e565a01425d4a9f90` (2026-11-10), for AJ-E1608's
codec tests (`tests/muse_serve.rs`). Each line is `{"dir": "client" |
"server", "raw": "<one wire frame>"}`; every value in them is the SDK's own
made-up fixture data.
