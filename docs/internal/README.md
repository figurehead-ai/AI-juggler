# Project internals

Working material for the people and agents who build AI Juggler. None of it
is needed to use AI Juggler or to contribute; start with the
[README](../../README.md), the [user guide](../guide/) or
[CONTRIBUTING](../../CONTRIBUTING.md) instead.

| File | What it is |
| --- | --- |
| [MAINTAINER-STEPS.md](MAINTAINER-STEPS.md) | One-time setup only the maintainer can do: signing, secrets, repo settings. |
| [IMPLEMENTATION-AGENT-PROMPT.md](IMPLEMENTATION-AGENT-PROMPT.md) | The brief given to AI agents that implement tasks. |
| [AGENT-HANDOVER.md](AGENT-HANDOVER.md) | State snapshot and rules for an agent picking up the work. |
| [agent-review-prompt.md](agent-review-prompt.md) | The brief given to AI agents that review the design. |
| [expected-workflow.md](expected-workflow.md) | The maintainer's original notes on the workflow AI Juggler should support, kept verbatim. |
