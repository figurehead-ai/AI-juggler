AI Juggler 0.3.5 lets a switch continue where you choose, in the Claude app (Desktop) or in a terminal (CLI), keeps the switch screen short with the details a click away, follows a conversation as it grows instead of reloading it, draws Claude app sessions the way the Claude app does, and names your Claude app profiles the way you named them.

## New

- **Continue a switch in Desktop or CLI.** The switch's last step asks where it continues: **Desktop**, the target account's Claude app profile ("Claude app · Work Max"), or **CLI**, Claude Code in a terminal. The one where the session already ran is chosen first and marked "Same as the original". The button says where ("Switch to Desktop"). In Desktop, AI Juggler hands the session to that profile's own window, starting the profile first if it's closed, and says "switched" only once the Claude app has taken it, with all its messages. When an account has no Claude app profile yet, Desktop shows why. On the first hand-off macOS may ask whether AI Juggler may send Claude a link: that's this.

## Improved

- **The switch screen is short.** It shows where it continues, one coloured line for what goes along ("Everything goes along · 8 items", click to see them), and only the choices you need to make. Explanations and the full details are folded until you open them. What goes along has an icon and a colour for each kind.

## Fixed

- **A conversation no longer empties or jumps while you watch it.** With a session's page open while you talk in the Claude app or ChatGPT, the conversation used to vanish for a moment and redraw from the top every few seconds, and on a long session it could show nothing at all. The page now follows the conversation: new messages and work are added at the end as they're written, what you've read stays where it is, and your scroll position is kept. Scroll up and earlier turns load a page at a time, however long the session.
- **A Claude app session looks like it does in the Claude app.** 0.3.4 folded each finished turn into one "Worked for 4 min" row. That's how ChatGPT's Codex draws a turn, not the Claude app. A Claude app session now shows what the Claude app's Code tab shows: every message in full, and each run of work between two messages as one line titled the way the app titles it ("Edited a file, ran 3 commands", "Opened a page", "Captured page"), one click from its steps. A message you send while Claude is working starts a new turn where you sent it. Sessions in ChatGPT keep ChatGPT's "Worked for" row.
- **Your Claude app profiles have the names you gave them.** The rail and Home called a profile by the name of the app's own folder ("b-work") while the Accounts page called it by its Claude Code folder ("work-max"). They now use the same name everywhere. A session you started in the Claude app is always listed under that app's profile, even if AI Juggler never saw it open. An extra "Claude Code" app you never use no longer appears with those sessions under it.
- **Starting a Claude app profile keeps it on its account.** Open, Keep alive and the switch start a profile the way your own launcher does, with the Claude Code folder its sessions use. Before, a profile AI Juggler started put its new sessions in the default folder, on another account.
- **You can switch from a Claude app profile again.** 0.3.4 held back every Claude app profile with "Claude Code hasn't done its first-run setup in a terminal", because sessions in the Claude app never answer Claude Code's first-run questions. Those profiles are offered again, saying "Its first-run setup is done as it switches". As it starts the session, the switch marks Claude Code's first-run setup as done in that profile (one setting in its own file; nothing else changes), with nothing to do in a terminal. A profile that was never signed in is still held back, with why.
- **A session's subagents and the sessions it started read as a tree.** The column beside a conversation now starts at **This session** (its main conversation) and branches with lines, like the Claude app's sidebar: **Subagents running**, **Sessions it started** and **Finished subagents**, each with how many. It also shows when the page is narrow; before, it could shrink to a thin strip there.

## Known issues

- A profile you've never opened while AI Juggler was running isn't listed yet. 0.4's **Apps** finds them (with your OK).
