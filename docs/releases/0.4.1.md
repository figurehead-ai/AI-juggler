## Move a Claude conversation to another account

Switching between two Claude accounts on this Mac can now **move** the conversation instead of copying it, and that's the default (D-93). The same conversation continues on the other account: every message, the sessions it started (archived ones stay archived), the agents it ran and its rewind points, with nothing copied and no extra disk used. The original account no longer lists it. **Copy** is still one click away on the switch screen.

- Works between two Claude app profiles, and between two Claude Code folders used in a terminal. Not yet between the app and a terminal: Copy carries those.
- Both app profiles quit and start again, so anything running in them stops; the switch screen says so, and won't start while a session in either is working.
- Nothing can be lost: AI Juggler keeps checked backups (clones that take no room until something changes), writes down every step before it takes it, checks every byte before and after the app reopens, and **Undo the move** puts both accounts back exactly, keeping anything done since aside.
- It never touches a sign-in, and never sends a message on your behalf: whether the other account answers is yours to check, and the switch says so.

## What's checked on the real tools

Switching a conversation between Claude Code and Codex has been run on the real tools (Claude Code 2.1.302 and 2.1.310, Codex 0.163.0) in throwaway projects, not only in AI Juggler's own tests:

- **Claude Code to Claude Code** (another subscription): the conversation, its rules, its task list, its subagents, its MCP servers, its folder and worktree, and switching back.
- **Claude Code to Codex:** the conversation, its rules, its task list, its MCP servers, its folder and worktree, and switching back. Subagents and file history don't move to Codex; the handover says so and names them.
- **Codex to Claude Code:** the conversation, its rules, its task list, its MCP servers, its worktree, and switching back.
- **Codex to Codex:** the conversation and its plan, once. The rest (rules, subagents, file history, MCP servers, folders, switching back) and two Codex accounts signed in side by side are checked only in AI Juggler's own tests so far: running them on the real tools needs a second Codex account, and the switch says so for this pair.
- **Codex sessions AI Juggler runs:** reading its limits before the first turn, a real approval and a question. Stopping, steering and compacting a Codex turn are checked against a stand-in for Codex, built from Codex 0.163.0's own description of itself.

When Claude Code or Codex updates, AI Juggler treats these as unchecked again until they're run on the new version.
