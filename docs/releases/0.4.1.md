AI Juggler 0.4.1 can move a Claude conversation to another account, shows the Floor as a building you see one floor at a time, and adds a round of fixes to Apps, Accounts, pools and tasks.

## New

- **Move a Claude conversation to another account.** Switching between two Claude accounts now **moves** the conversation by default instead of copying it. The same conversation continues on the other account: every message, the sessions it started (archived ones stay archived), the agents it ran and its rewind points. Nothing is copied and no extra disk is used. The original account no longer lists it. **Copy** and the other choices stay on the switch screen.
- **Move is checked and can be undone.** AI Juggler keeps checked backups that take no room until something changes, writes down each step before it takes it, and checks every byte before and after the app reopens. **Undo the move** puts both accounts back exactly and keeps anything done since aside. A list of your moves shows each one.
- **What Move covers.** It works between two Claude app profiles and between two Claude Code folders used in a terminal. It does not work between the app and a terminal yet: Copy carries those. Both app profiles quit and start again, so anything running in them stops. The switch screen says so and won't start while a session in either is working. Move never touches a sign-in and never sends a message for you. Whether the other account answers is yours to check.
- **The Floor is a building.** The new building view is a cross-section of the building on its street. You see one floor at a time and take the lift to the others. Labels change with zoom, apps that have been idle a while sit apart, and the lighting follows day and night on your clock.
- **A new look for the Floor.** Rooms have better light and soft shadows. People have faces that show their state. It is the default look now, in both Pixel art and Full resolution.
- **The View menu on the Floor.** It sits top right and lets you choose what the Floor shows. Hover a person to see what they asked or did last and where to answer. The whiteboard opens Tasks on that App's tasks, and an Account's door opens its page.
- **Out and Low say what they mean.** An Account or App that is out of room carries one clear Out mark everywhere: Home, the rail, the header, every switch target, and the Floor. Out says when it resets, in your own clock. Low shows how much is left. There is no banner across the top of a page for it any more.
- **Run in AI Juggler.** An ended session now offers **Run in AI Juggler** beside Resume, so after you've worked in its terminal you can carry the same conversation on without one. For Claude Code this is Beta (Settings › Sessions › Run without a terminal). A session running without a terminal points you at its earlier turns until it has new ones.
- **Go to it opens the exact session.** For a Claude app session, it opens that session in its own profile and starts the profile first if it is closed.
- **Back and Forward.** ⌘[ and ⌘] (and the ‹ › buttons) go back and forward between pages. A session's App chip opens its page in one click.
- **Apps and Accounts know each other better.** One Account can have several Apps. An App page shows where it runs and the room it shares with other Apps. A CLI App's launch settings are a tab of their own, and Settings has Show in the rail for each App. Every name opens its own page.
- **Pools can move and be tidied.** A node's menu moves it to another pool. Option and an arrow nudge a node 8 px, and Shift makes it 32. A pool's card has a menu to open its canvas, rename it or delete it, and says where its sessions go.
- **Subagents show more.** A quiet one says when it last did something. A session's Usage names the three subagents that used most, each a link. Esc goes back one step on a subagent's page.
- **A tool's own words about a wait.** A Codex in a terminal that is waiting on a call now says so.
- **Keep a project apart.** A project's menu has **Keep it apart…**: it sets up a sealed pool on that project in one step, so its sessions stay out of every other pool and nothing leaves it through AI Juggler.
- **View › Only › Pool.** Once you have pools of your own, the rail can show just one, and search takes `pool:`.

## Improved

- **Tasks.** To do, Done and Cancelled are one click away on the board. A task waiting on your review also shows in Needs you. A card names its App, and a card in review has Approve and Send back… on it. Search reads each task's brief. You can filter by an App.
- **Move around the plan with the keyboard.** The task plan works like a tree: ↑ and ↓, → to open or go in, ← to close or go up.
- **Projects have their own menu.** Each row has ⋯, right-click and ⇧F10 with Open its page, Show in Finder, Rename… and Forget…, the same in the rail. An empty Projects screen says how a project appears and offers New project….
- **A pool's page and the rail.** The window's title says the screen, and a pool's page says Pools › its name. Pool shows in the rail once a pool of yours has members.
- **Menus take type-ahead.** Type a few letters in any menu to jump to an item.
- **Settings pages say what they do.** Every Settings pane has a short footer for each section.
- **Pickers show suggested first, then all.** An empty option is never in the top group; it stays last.
- **New session says why.** A first guess says why it is a guess, the folded options say "the defaults" when nothing is set, and an App that is out of room offers another Account's App.
- **Starting is quicker.** The conversation list is saved and read again at the next start, so only transcripts that changed are read. It builds after the window shows. Session folders are watched for changes instead of listed again.
- **The window rests when hidden.** Its own polling stops while it is hidden, and an answer that hasn't changed redraws nothing.
- **Profiles are clearer.** A profile's page lists each session once, by the app's own title. Add brings in its folder and sessions too. Start says when the app is up. Forget says why it can't when the app is running.
- **Notifications for limits.** Usage levels work on measured or estimated windows, and estimates say "about".
- **Subagent pages are honest about their source.** Each says where its details come from, and a read that fails says so with Try again instead of an empty table.
- **Names are never cut.** Your apps cards line up and keep a name whole, and the Keyboard shortcuts sheet no longer clips keys.
- **Better tidy-up after a crash.** A helper a session started in its own process group is cleaned up after a crash. Cleanup history filters by project and pages back with Show older.
- **Stronger security.** Web views are locked down, commands only take ids or paths you chose, a task's private brief is removed once its session has read it, and the updater has a standby signing key.

## Fixed

- Clicks on the Floor landed where it drew them, and one press opens one Floor, not several.
- Nothing in the Floor's office covers its controls. Flags keep clear of the alert banner and the lift's number.
- A logo the Floor's cache lost is drawn again, and a closed Floor window releases its memory.
- Quitting AI Juggler with a log out or a kill is no longer counted as a crash.
- Apps could be started by a door that didn't start them. Start and Restart now work from every door, and only you add an App.
- A Claude app profile was told to sign in in a terminal and called signed out. It no longer is.
- Sign-ins read again when the window comes back, and Usage says Not signed in when it is so.
- A Codex first start in a new folder asked its trust question where you couldn't see it, and Start hung on "Starting…". It now asks in view.
- Pool members that share a name are numbered by when they started, and a member is never named by a branch that names no work.
- A pool's Lead is one session. An App, Account or tool can be a Member, Reviewer or Observer, but not Lead; a pool that had one gets a Member there, and AI Juggler says so once.
- A refused sender in a pool is told so. A pool's rules show on the canvas after a line's talk changes.
- A pool's page no longer asks to let agents see each other when it is sealed. A sealed pool's Claude Code sessions now also refuse Claude's own messages between sessions and can't send them, from their next start.
- A boot screen that fails to open now says so and offers Reload.
- Text fields no longer autocorrect.
- A session's terminal no longer opens 14 columns wide after you switch tabs.
- A session's page uses the same name as Home and the rail, and doesn't open on a Pools tab for a session in no pool.
- The conversation card says "not saved" when a conversation is held in memory and never written.
- A running session's menu keeps Archive, greyed, and says why.

## Known issues

- **Going back to 0.4.0 from 0.4.1.** 0.4.1 updates AI Juggler's own data. The copy it keeps on the way makes going back possible: Settings › About & updates › Go back to an earlier version. That copy is from before the update, so what changed in 0.4.1 isn't in it. Your Claude and Codex folders aren't affected either way.
- Move to account is not available between the Claude app and a terminal. Use Copy for those.
- Claude Code without a terminal is Beta.
- Switching a conversation between Claude Code and Codex has been run on the real tools (Claude Code 2.1.302 and 2.1.310, Codex 0.163.0) in throwaway projects. Claude Code to Claude Code covers the conversation, rules, task list, subagents, MCP servers, folder and worktree, and switching back. Claude Code to Codex covers all of that except subagents and file history. Codex to Claude Code covers the conversation, rules, task list, MCP servers, worktree and switching back.
- Codex to Codex has been run on the real tools for the conversation and its plan only. The rest is checked only in AI Juggler's own tests, because it needs a second Codex account, and the switch says so for this pair.
- When Claude Code or Codex updates, AI Juggler treats these as unchecked again until they're run on the new version.
- The Floor is on macOS only. Windows gets it in 0.6 and Linux in 0.7.
