AI Juggler now watches your Mac: CPU and memory for every Claude tool, including the ones it didn't start, calm alerts when the Mac is under pressure, and advice before you start something heavy. Codex joins Claude Code as a second tool, and updates now keep a way back.

## New

- **This Mac on Home.** How much room your Mac has, what's using it (every Claude Code session, the Claude app's windows, `claude` in a terminal, including ones AI Juggler didn't start), and which session is the one worth a glance. Heavy sessions show in Needs you, in the session list and in the session's header. Memory for tools AI Juggler didn't start is marked "about", since it can't be measured exactly.
- **Advice before you start.** Starting a session on a Mac that's already tight says so, and suggests what to close first. It's advice only: Start always works.
- **Calm alerts.** When memory, swap, CPU or disk get tight, Needs you says so once, and clears by itself when things settle. A full disk is called out only when it's really short (under 5 GB).
- **Codex, beta.** Codex setups show up beside your Claude ones when you add accounts, come in as copies, and their sessions show up in the session list. You can switch a session between Codex and Claude Code; the conversation goes with it.
- **A way back after updates.** Before an update changes AI Juggler's own data, it keeps a copy, so you can go back to the earlier version from Settings. If you open an older version on newer data, it says so and offers to go back, instead of just refusing to start.

## Improved

- **Updates say what they bring.** The update prompt shows the version and what's new before installing, says Beta when you're on Beta, and never restarts during a session. A failed update leaves your version as it was and offers Try again.
- **The session list's projects.** Projects you haven't run anything in yet sit under a short Projects heading, each with when you last worked there, how many conversations, and with which accounts. Worktrees count as their repository, clones of one repository are grouped, and every group folds.
- **Plain words in the details panels.** No more internal codes or "No data": a value that isn't measured yet says so, and a row with nothing to show stays hidden. The tool chip in a session's details opens the tool.

## Known issues

- **Going back to 0.0.8 or earlier from 0.0.9.** 0.0.9 updates AI Juggler's own data again. The copy it keeps on the way makes going back possible: Settings › About & updates › Go back to an earlier version. Your Claude folders aren't affected either way.
