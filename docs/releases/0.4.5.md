AI Juggler 0.4.5 is a round of fixes.

## Fixed

- **A session you didn't name says what it was about.** A session with no name of its own is now named by the first words of the first thing you asked it, as `claude --resume` and Codex's list of sessions show it. Its folder and start time ("billing · started 4:46 PM") name it only when it has no first request. Slash commands, a command's output, a tool's output and a session's carried-over summary ("This session is being continued…") are skipped, and a pasted key or a bare file path never becomes a name. Home, a session's page and the lists no longer name a session by the last thing you asked it, so they agree with the rail.
- **A name the Claude app gave a session is kept.** A session the Claude app named, or one you renamed with `/rename`, showed its first request instead. It now shows the same name as the Claude app.
- **Home's "In the last 12 hours" names each session.** Its rows named only the app a session ran in ("Claude Code CLI · Work · api · Finished"), so a long night's rows read alike. Each row now leads with the session's name, the same one the sidebar shows, with its app, project and how it ended under it.
- **A session's time in the sidebar is no longer cut short.** Beside a short project name, the time could lose its last letters ("api · 2 d a…") with room to spare. It now shows whole; a long project name gives way first, as before.
- **Closing a hidden window no longer quits AI Juggler with sessions running.** With sessions running, closing the window or pressing ⌘Q brings the window forward and asks first. If that question never came up on screen within 3 seconds, for example when another app pressed the close button of a hidden window, AI Juggler quit as if you had chosen Quit anyway, and its terminal sessions ended. Now it quits that way only when the window was on screen and stopped responding; otherwise it waits for your answer. A second ⌘Q still quits at once, and with nothing running a close quits right away, as before.

## Known issues

- Going back to 0.4.4 works as before (Settings › About & updates).
- The Floor is on macOS only. Windows gets it in 0.6 and Linux in 0.7.
