Usage now shows only what was actually measured: no more made-up "100% left" or reset times, tokens are counted once, and Codex limits come from Codex itself.

## New

- **Codex limits.** Codex accounts show how much of their limit is left, read from what Codex itself records, with when it was measured ("as of 12 min ago") and the credit balance. Only the limits Codex reports for your account are shown.
- **Manage accounts.** Right-click an account, or open its ⋯ menu, to rename it, make it your default, or remove it. Removing an account you use where it is never touches its folder, and its history stays readable. Each project can also have its own default account for new sessions.
- **Prices for current models.** Session costs now use the current Claude and GPT prices from the vendors' own price pages. A model without a known price says "No price for this model yet" instead of showing $0.

## Improved

- **The same numbers everywhere.** Home, Accounts, Usage, New session and the session details now show the same figures and words for each account.
- **After a limit resets.** When a limit has reset and nothing newer has been measured, it says "Not measured since the reset" instead of an old figure.
- **The memory alert.** Home shows it once, in Needs you, without covering the page, and it names what is using the memory, for example "The Claude app is using about 16 GB across 3 windows". This Mac's status now agrees with it.
- **When a screen hits a problem.** It says so, with Try again and Copy details, and the rest of the window keeps working.

## Fixed

- **"100% left" for accounts in use.** An account with no measured limit showed a full bar. It now says "Not measured yet" and shows the tokens used.
- **Made-up reset times.** A reset time shows only when the tool reported one.
- **Tokens counted twice.** Claude: a reply in several parts was counted once per part. Codex: cached and reasoning tokens were counted twice. On first launch AI Juggler re-reads the transcripts still on your Mac, so past totals and costs are corrected too.
- **Usage showed an empty window.** It opens again, with any missing value shown as missing.
- **Screen Recording stayed "Not allowed".** macOS only reports it after AI Juggler reopens, so the welcome now offers Reopen AI Juggler, and says Allowed once macOS does.

## Known issues

- **Claude limits.** A Claude account shows how much is left only once a session started in AI Juggler has reported it. Until then it says "Not measured yet", with the tokens used.
- **Sessions started outside AI Juggler.** The session list shows the sessions you started in AI Juggler, plus the projects found in your history. Every session, wherever you started it, is coming in a later version.
- **This Mac** counts less memory than is really used when a session starts other programs, such as a dev server.
- **Some prices are missing.** Older Codex models (gpt-5-codex, gpt-5.1-codex, gpt-5.2-codex), Codex's automatic reviews and Claude Haiku 5.5 say "No price yet".
- **Copies made with an earlier version.** If you made a copy of a Claude setup before 0.0.12, it may hold a copy of the original's sign-in. If either one asks you to sign in again, sign in once inside the copy.
- **Going back to 0.0.12 or earlier from 0.0.13.** 0.0.13 updates AI Juggler's own data, to remember removed accounts. The copy it keeps on the way makes going back possible: Settings › About & updates › Go back to an earlier version. Your Claude and Codex folders aren't affected either way.
