Codex now shows up when you bring in your accounts, however you open AI Juggler, and a copy of a Claude setup no longer carries its sign-in file.

## Improved

- **First run and Add account.** "Find my accounts" on an empty Home goes back to first run, with every tool at once, and adding an account later no longer asks for computer access again. A single setup is worded for one, and the tool chooser is in plain words.
- **The session list.** It opens at its full width, so project rows show their details. A folded project still shows what needs you inside it, and the filter row wraps instead of cutting off Filters.
- **Projects and tools.** A project you've only worked in outside AI Juggler says what was done there. Each tool has its own mark, and a tool that doesn't report its limits, such as Codex, says so instead of showing empty rows.
- **Plain words.** The session details read in plain words, with no codes or design notes. A session's cost reads "$0.69".
- **Going back.** "Go back to an earlier version" links straight to that version's release page.

## Fixed

- **Codex wasn't found when AI Juggler was opened from Finder.** Tools installed with npm or Homebrew, like Codex, couldn't start. AI Juggler now uses your own shell's PATH to find and run them.
- **A copy of a Claude setup carried its sign-in file.** Copies now keep the sign-in with the original, as Codex copies already did, so the two never sign each other out.
- **Opening AI Juggler while it's already open and not responding.** The second launch now waits a moment for an answer, and if none comes, says how to quit the stuck one.

## Known issues

- **Copies made with an earlier version.** If you made a copy of a Claude setup before this version, it may hold a copy of the original's sign-in. If either one asks you to sign in again, sign in once inside the copy.
