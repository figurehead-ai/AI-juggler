This Mac now counts everything your sessions start, and session costs match their transcripts, including Codex compactions and resumed conversations.

## Improved

- **This Mac counts what sessions start.** Programs a session starts, such as a build or a dev server, count toward it within seconds instead of after a delay. The memory total now matches what macOS reports.
- **Every Claude app window.** This Mac lists the three largest and says "and N more" for the rest, instead of leaving them out.
- **Resumed conversations.** When a conversation is resumed, its earlier messages are counted once, under the session where they first happened, so per-session costs no longer double up. Account totals were already right.
- **Safer tools.** AI Juggler runs system tools and git only from fixed system places, and only when nobody else can change them, never through your PATH. Without Apple's command line tools, worktree actions say how to install git instead of opening Apple's install dialog.

## Fixed

- **Codex: tokens after a compaction.** The tokens Codex spends compacting a long conversation were missed. They now count once.
- **Claude Code's search helpers counted as sessions.** Leftover search processes from finished sessions showed as "Claude in a terminal" on This Mac.
- **"Database is locked".** Two background writes at the same moment could make one fail instead of waiting its turn.
- **Usage totals after an update.** On first launch AI Juggler re-reads the transcripts still on your Mac once more, so earlier totals use the corrected counting.

## Known issues

- **Monitoring while the Claude app is very busy.** With a large build running under the Claude app, AI Juggler's monitoring can use a little over 1% of one processor core, above its 1% target. A fix is in progress.
- **Claude limits.** A Claude account shows how much is left only once a session started in AI Juggler has reported it. Until then it says "Not measured yet", with the tokens used.
- **Sessions started outside AI Juggler.** The session list shows the sessions you started in AI Juggler, plus the projects found in your history. Every session, wherever you started it, is coming in a later version.
- **Some prices are missing.** Older Codex models, Codex's automatic reviews and Claude Haiku 5.5 say "No price yet".
- **Copies made with an earlier version.** If you made a copy of a Claude setup before 0.0.12, it may hold a copy of the original's sign-in. If either one asks you to sign in again, sign in once inside the copy.
