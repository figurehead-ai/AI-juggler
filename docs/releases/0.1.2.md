AI Juggler 0.1.2 keeps its window responsive while many sessions are working.

## Fixed

- **The spinning wheel.** With several sessions running, the window could stop answering for moments at a time: every change in a session made it read its lists again on the window's own thread, including a sign-in check per account. Those reads now run in the background, a burst of changes reads them once, and the sign-in check is remembered for a short while.
- **Large token counts.** A busy account's tokens read "10329M tokens used"; they now read "10.3B".
