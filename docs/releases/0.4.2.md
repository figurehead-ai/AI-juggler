AI Juggler 0.4.2 shows exactly the apps that are running: every open app or profile is under Open now, whether or not it has a session, and a desktop app is never confused with a terminal tool on the same account.

## Improved

- **Open now is what's open.** Every app and profile that is running is under Open now, even with no session in it. Inactive apps lists only the ones that aren't running, and no app is ever in both.
- **Running, not added.** An app AI Juggler recognises that is running but that you haven't added has its own row with Add. It is never added for you.
- **Desktop or CLI, at a glance.** Every app has a mark beside its icon: a window for a desktop app, `>_` for a command-line tool. A terminal tool's name says CLI ("Claude Code CLI · work"), so the Claude app and Claude Code on the same account never look like one app shown twice.
- **Names stay readable.** In the narrow rail, an app's profile name keeps its room. When it has to be cut, it's cut in the middle, so the part that tells two profiles apart stays visible ("book…th-luka"). The full name shows when you point at it.
- **The Codex app.** Codex in ChatGPT.app is now the app of your Codex account, and its threads are listed under it rather than under the Codex CLI.
- **Every session under the right app.** A session belongs to the app its process runs in. A finished one belongs to the app it was last seen in, or the app it was started from. A terminal session is never filed under a Claude app profile.
- **Pinned sessions.** A pinned session that has ended stays pinned under its app, but it no longer makes the app count as open.
- **"N accounts out" shows which.** The header's count opens Accounts filtered to the accounts that are out, each with when it's back and the account with room to use instead. Clear the filter with ×. Every other count in the header opens the exact view it names.
- **Launches and quits show at once.** An app you open or quit shows in AI Juggler within two seconds.
- **The Floor matches the rail.** Each room is named as the rail names its app, with the desktop or CLI mark, and a room is lit while its app runs. A Mac alert is now one small chip, no longer a red scene.

## Fixed

- Running Claude app profiles no longer show under Inactive apps as "Running", and the running default profile no longer shows twice.
- A profile that shares the default profile's folder goes by its own name instead of "Default".
- The Codex app was missing from Open now and from Accounts while it ran.

## Known issues

- Going back to 0.4.1 from 0.4.2 works as before (Settings › About & updates).
- The Floor is on macOS only. Windows gets it in 0.6 and Linux in 0.7.
