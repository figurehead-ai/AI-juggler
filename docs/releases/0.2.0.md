AI Juggler 0.2.0 points every switch at the account with the most room, gathers what needs you in one place, lets the agents in your sessions work together, and fixes what the 0.2 walk-through and the live tests found.

## New

- **One place for what needs you.** A bell at the top right opens the notification centre (or press ⌥⌘N): **Needs action** is your Needs you list, and **Earlier** keeps 30 days of what happened, such as an account with room again, a finished session or a crash that was restarted. The bell, Home, the Dock icon and a new menu-bar item show the same count, even with the window closed. Snooze or mute any item from its ⋯ menu: a snoozed item leaves the count until it's due back. Nothing acts by itself.
- **Banners when an account runs low.** An account almost out of room gets a banner that says how much is left, when it resets and how many sessions use it, with **Hand over…**, **Queue for the reset** and **Snooze 1 h**. macOS notifications can now also tell you when an account is almost out of room, has room again, or a crashed session was restarted. Each kind is off until you turn it on.
- **This project's notes can travel with a switch.** Claude Code keeps notes about each project in each account's own folder, so the account you switched to started without them. When it lacks some, the switch now asks "Work Max's notes for this project (3) aren't on Personal: copy them?". The box is never ticked for you, and **Undo** takes the copies out. For Codex, which keeps no such notes, the switch offers to include them in the handover. A note that looks like it holds a key or password is left out, and the switch says which one.
- **Codex runs without a terminal.** A Codex session AI Juggler starts now runs inside AI Juggler by default. Its page shows the conversation as it happens, and you answer its questions and approvals from the page or from Needs you. **Open in terminal** continues the conversation in Codex's own terminal once the turn ends. AI Juggler asks "Trust this folder?" once per folder and never changes Codex's settings file. These sessions come back when AI Juggler restarts. To keep the terminal, choose **In a terminal** in Settings › Sessions › How sessions run.
- **Claude Code without a terminal (Beta).** Turn on Settings › Sessions › **Run without a terminal (Beta)** to start a Claude Code session with no terminal and answer its questions here. It's off by default and picked one session at a time. It runs your own Claude Code with your own sign-in, but Anthropic may count it as Agent SDK use rather than ordinary Claude Code use.
- **Pools: sessions that work together.** Choose **Move to pool…** on a session to group it with others, name the group and pick a lead. Every project also has its own pool. A pool's page shows what each member is doing, the step it says it's on and the files it changed most recently. Putting a session in a pool never starts, stops or types into it.
- **Messages between agents.** Agents in a pool can write to each other and to you, and share documents. A message waits in the recipient's inbox. It goes into a session only when you click **Deliver** or the pool allows it, and only between turns: never while the tool is asking you something or while you type. A session in a terminal is never typed into. It's told it has unread messages and reads them itself. Long back-and-forth chains pause until you say so.
- **Tasks your agents keep.** Agents add tasks, take a ready one (only one session gets it), say where it stands and hand it back with a note. Bigger work shows as epics and stories under **Plan**. The agents write the tasks, and you see and track them. On a task you can **Approve** or **Send back…** one in review, **Free it** when its agent's session has ended, **Cancel task**, or **Start a session for it…** on the account you pick. To add or change work, tell an agent.
- **You decide what agents may do.** Each pool has a level: Read, Work together, Full or Custom. Anything above the level waits in Needs you with **Allow once**, **Always allow in this pool** or **Deny**, and you can take back any rule you made. No level lets an agent start a session, pick an account or see a password or key.
- **OpenCode, Grok Build and Kimi Code.** All three can now be added as tools next to Claude Code and Codex, each account in a folder of its own. You can start their sessions in AI Juggler and see them in the list.
- **Accounts through another service.** **Add account › More › Through another service** adds a subscription such as OpenCode Go or Kimi that runs Claude Code or Codex at its own address. You paste its key once. It goes into AI Juggler's own Keychain item and is never shown again or written to a file.
- **Processes.** A new page, which replaces Cleanup (⌘⇧C), shows every process your sessions and AI apps run, grouped by app and session. A desktop app's own processes are counted once, not once for each session. **Include other apps** adds the rest of your Mac, by name and memory only. **Stop…** checks a process again and tells you what stopping it will do before you confirm. A process another app's session left behind is stopped only when you ask, and only after that session has ended.
- **A Subagents tab.** A session that started subagents gets a tab listing each one: what it was asked, whether it's running, done or failed, and how long it took. With Subagents shown in the list's View, "+2 agents" on a row now counts subagents for every tool, in other apps' sessions too.
- **Your menu.** The avatar at the top right now holds Settings, This Mac, Processes, Privacy, Appearance, keyboard shortcuts, help, Report a problem… and About and updates.
- **New tool versions.** Once a day, AI Juggler checks npm's public registry for the newest version of each tool you have an account on. A newer version shows on that tool's page with the command to update it yourself. AI Juggler never updates a tool, and a checkbox on that page turns the check off.

## Improved

- **Switch to the account with the most room.** **Continue on another account** now ranks accounts by how much room they have left, the way Home's Runway does, and marks one **Suggested**. Each account shows its room ("75% left this week") and when it resets. New session and the limit dialog use the same order and the same Suggested account, and New session says why it picked an account ("your default", "Suggested: the most room").
- **Out of room, said plainly.** An account with no room left is still offered, at the end of the list, as "Out of room until Thu 08:00". The switch explains what picking it means: the conversation stops at that account's limit straight away. Its last button reads **Switch anyway**.
- **Switch any session, from anywhere.** **Continue on another account** is now in the row menu and in ⌘K for sessions that other apps run, as well as for AI Juggler's own. ⌘⇧H opens it for the session whose page is open. The out-of-room banner and Home's row continue that account's newest open session instead of opening the account's page.
- **Switching, measured end to end.** In live tests on real accounts, a switch between two Claude accounts carried every turn, tool call and result, the task list, subagents and connected tools. Each test asked the new session about facts given early, midway and late in the conversation, and it answered every one. Switching to Codex and back, the new session also answered every fact; there, each tool call arrives as one line saying what it did.
- **What the switch carries, in plain words.** The setup list starts with what this conversation used. Everything else waits under one closed line. MCP servers and skills go along only where the other account has them or you set them up. The conversation is "carried over", never "moved".
- **The list stays put.** Open now keeps each session in its place while it works, waits or asks you something; only its dot and word change. Pin a session to the top, drag rows and places, or use ⌥⌘↑ and ⌥⌘↓. The **Your order ▾** menu switches back to **Latest activity** if you prefer the old behaviour, or sorts by **Name**.
- **New shortcuts: ⌘N is now New session.** New project moves to ⌘⇧N, and the notification centre is on ⌥⌘N. The shortcuts list (?) and ⌘K show the new keys.
- **⌘K does things.** It lists the selected session's actions first (type "switch" to find Continue on another account…). Then come New session…, every screen with its key, Notifications and Keyboard shortcuts, followed by sessions, projects and a History search.
- **Keyboard and screen readers.** A "Skip to page" link is the first stop. The session list is one stop, and you move inside it with ↑ ↓ Home End: from a fresh start the page is a few Tabs away instead of 84. Opening a page puts the keyboard on that page, and each step of the switch puts it on the step's heading. Screen readers no longer hear "terminal" before each session.
- **The list folds on narrow windows.** Below 1100 px wide, the list folds to icons by itself, so even the smallest window has room for the page. Folded, it shows the same Needs you count as the bell, then every open session as its app's or tool's icon, with its state.
- **Accounts by your names.** Usage, Accounts and Home's Runway name each account by the names you gave it, never by the team name repeated on every line.
- **This Mac and memory pressure.** This Mac lists every app's AI sessions among what's using memory. A memory alert now says what to quit or stop, and that nothing is blocked.
- **The first start says it's reading your history** instead of showing "0 tokens" and "Not measured yet" for minutes. The figures fill in as soon as the read is done.
- **Tokens and costs mean one thing.** "Tokens" counts input and output on every screen, as Usage does. Every cost is marked as an estimate of what the API would charge, not your bill.

## Fixed

- **Switching between Claude accounts failed for some sessions.** A session with file history could fail with "source changed during the switch". It switches now, and its file history goes with it.
- **The task list was lost on a switch between Claude accounts.** Recent Claude Code versions keep the task list apart from the conversation, so the other account started with an empty one. It's carried now, and when you switch back the session is told how the last account left it.
- **Stop didn't end a busy session in AI Juggler's terminal.** That also made a switch's **Stop now** give up with "The session didn't stop, so nothing was switched". Stop ends it now.
- **Sessions started while AI Juggler ran inside a Claude Code session.** If you opened AI Juggler from a terminal in a Claude Code session, the sessions it started took that session's settings: their conversations weren't saved, and their requests went where that session's did. They start clean now.
- **A rule lost on the way back from another tool.** Switching back from Codex to Claude Code, a rule only `CLAUDE.md` stated could stop applying. The update the session gets on return now names the rules files the work followed.
- **Session titles in AI Juggler's words.** A session could be titled with AI Juggler's own handover or message text. Titles now come from the first thing you asked, also after a switch.
- **The folded list said "All clear"** while something needed you.

## Known issues

- **Agents work together only in sessions AI Juggler starts.** Messages, tasks and agent access reach a session through tools AI Juggler adds when it starts it, after you say yes once. A session you start yourself in a terminal or another app can't join in.
- **Switching with the new tools.** A switch can continue a conversation in OpenCode or Grok Build by handing it over, but Kimi Code can't be switched to or from yet. Switching to or from an account through another service is never a proven switch, because the model behind it changes.
- **Task lists after a hop through Codex.** Codex keeps no task list of its own. When you switch back to Claude Code, the update says what Codex finished, but Claude Code's own list may still show those items as open.
- **Subagents of OpenCode, Grok Build and Kimi Code** are listed, but their own conversations can't be opened yet.
- **Limits for accounts through another service.** OpenCode Go's limits are an estimate from what this account's sessions used, and Kimi's are unknown: neither service tells other tools what's left.
- **Going back to 0.1.9 or earlier from 0.2.** 0.2 updates AI Juggler's own data. The copy it keeps on the way makes going back possible: Settings › About & updates › Go back to an earlier version. Pools, messages, tasks and notification history from 0.2 aren't in that copy. Your Claude and Codex folders aren't affected either way.
