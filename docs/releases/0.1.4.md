AI Juggler 0.1.4 fixes updates that stopped before they started.

## Fixed

- **Updating.** An update could stop with "Couldn't make the backup … something that looks like a secret" when a project's name only contained a word like "task-…" or "desk-…". Words like these no longer count as keys, and the backup made before an update, which stays on your Mac, no longer stops an update at all.

## Known issues

- **Updating from 0.1.1 or 0.1.2.** Those versions still check the old way before they update, so if yours stops with that message, download 0.1.4 from the releases page and drag it into Applications once. Updates work from then on.
