A small update to the first beta: fixes for what showed up in its first hours of use.

## Improved

- **First run says where each setup is open**: every Claude Code setup it finds now says whether it's open right now in the Claude app or in a terminal. Setups are grouped as your Claude profiles, the default setup and others, and the default `~/.claude` is called "Default", since the Claude app uses it too.
- **Sign-ins on Home**: an account that needs its sign-in now shows on Home under Needs you, with Sign in right there, instead of a separate screen. The item clears by itself once you're signed in.
- **"Where we looked"** in first run uses plain words for each place it checked.

## Fixed

- The **?** at the bottom of the session list now opens the guide to what the icons and words mean. Before, it opened out of sight. The guide also uses the list's own words now.
