# 0.4 switching matrix: every combination, and what proves it

> **Superseded for accounts (2026-11-11, ADR-0032's evidence):** a lab
> starts a tool only on the sanctioned test profile (`aij-test`), AI
> Juggler Dev's own Lab App folder, or a folder under a throwaway lab home,
> never on one of the maintainer's own tool folders (`~/.claude`,
> `~/.codex`, `ClaudeCodeProfiles/*`). Labs run here from 10-25 to 11-07
> started 62 Claude CLI sessions on two real profiles' folders, which then
> showed as "CLI" Apps on the maintainer's screens. AI Juggler Dev now
> refuses such a start (`lab_scope::refuses_real_folder`), and so does the
> switch lab.

Switching is why people use AI Juggler (the maintainer, 2026-11-05: "migration, monitoring, those are main reasons"). This page lists every combination a switch can meet, the unhappy paths among them, and the test or live check that proves each. ADR-0028 and SPEC §7.7 hold the design; this is its evidence.

Legend:
- **U**: unit or integration test (named);
- **K**: conformance kit;
- **L**: live check on the maintainer's Mac (the `aij-test` Claude app profile; never a profile in daily use);
- **—**: not applicable, and why.

## 1. The dimensions

| Dimension | Values |
|---|---|
| Entry point | the session page's Switch, Continue on, the rail's menu, a notice's action, Home's Needs you, the inspector |
| What's on screen | the session's own page; another page (a project, an App, an Account); a global banner over any page |
| Source | Claude Code in a terminal; a Claude app profile (Code tab); Codex CLI; Codex desktop |
| Target | the same tool on another account, in a terminal or in a desktop app profile; another tool (handover note) |
| Family | none; 1 child; 20 children; two levels; archived children; a hand-off child |
| Automation | none; Auto-fix on an open PR; Auto-fix on merged PRs only; "Auto-fix my next PRs"; a Codex goal (active, usage-limited, paused); a Codex heartbeat |
| App state | source app running or closed; target app running or closed; either quit and restarted by the user, by AI Juggler, or never |
| Ids | free on the target; taken (a collision: fork) |
| Afterwards | stay; switch back (delta); switch on to a third account; switch back to an earlier one |
