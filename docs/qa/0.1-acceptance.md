# 0.1 acceptance checklist

0.1.0 is cut only when every item below reads **PASS**, with its evidence
linked. This is the maintainer's rule after testing 0.0.12 on their own Mac
(2026-10-21): the core works, verifiably, on a real multi-account Mac.

How it's kept:

- Each item records PASS or FAIL, the date, the release head it ran on, and
  an evidence link. TODO means it hasn't been run yet.
- A failure is fixed, and then **every item the fix touches is run again**
  on the new head. A PASS on an older head counts only when nothing it
  covers has changed since.
- Journeys run on the replica (`just replica`, AJ-E1531), never on anyone's
  real data. The real-data pass (§3) is run by the QA session through the
  Dev bridge, read-only, and it prints redacted counts and mismatches only.
