# 0.4 completion

0.4.0 reached beta (2026-11-06) without its whole scope (D-83). This page
is the audit of every task the roadmap's 0.4 section names, requirement by
requirement against the code, and the order the rest is built in. It ships
as 0.4.x from `release/0.4.1`, with the maintainer's test findings, before
any 0.5 feature work.

`python3 scripts/release_scope.py report 0.4` is the live count. A task
counts only when its header says DONE and its evidence manifest has a PASS
line for every numbered requirement; release PRs, the nightly of a new
minor and every promotion fail otherwise.

**Audit, 2026-11-06:** 130 tasks named; 0 proven (34 marked done, none
with a PASS line per requirement); 96 open. Below, what each still needs.
"Evidence" means the manifest with a PASS line per requirement.

## Order

1. **Security and the architecture under it (E20).** 0.4 is the release
   that makes AI Juggler safe to recommend; nothing is promoted before it.
2. **The requirement gaps in shipped features** (E19, E21, E28, E29, E30,
   E31, E32, E35), smallest first within each.
3. **Validation by use and the evidence** (E33, E35's walks and gallery,
   a manifest for every task), on the replica and the throwaway lab.
4. **The maintainer's steps** (bottom), asked for once each, exactly.
