# Shortest paths (Builder only — never in a tester's brief)

What the app's own words make the shortest path for each flow, for the stop rule ("twice the shortest path plus 5 steps") and for judging detours. Written before any walk, from the 0.4.1 build.

| Flow | Shortest path | Steps |
|---|---|---|
| M1 / D1 / R1 First run | First-run screen › its primary (find what's on this Mac) › review what it found › Add / Done › Home lists the accounts and apps | 3–4 |
| M2 What needs me | Rail "Needs you" (or the bell) › the waiting row › its page | 2 |
| M3 Room left | Home's "Runway by account" (or Accounts) › read room and reset › New session › Start (the usual pick, or Change app) | 2–4 |
| M4 Out mid-feature | The session's page › "Continue this session in another app…" (or its switch card) › pick the target with room › Switch | 3–4 |
| M5 Back after reset | The bell's "has room again" › Switch back (or the session's switch card back) | 2 |
| D2 Morning triage | Home's "Since you were away" or the rail's Needs you › the waiting one › back › the stuck one | 3–4 |
| D3 Find one of fifty | ⌘K › type "login api" › ↩ (or History › search) | 2–3 |
| D4 The laptop is struggling | Header's cleanup count (or This Mac) › Processes › the leftover › Stop | 3–4 |
| D5 Start a batch | New session › Change folder api › Start; New session › web › Start (the pick has room) | 4–6 |
| R2 Right account for the client | New session › Change folder (Client A) › Change app (Client A's account) › Start › the session's chip names the account | 4 |
| R3 Who touched this repo | Projects › the repo › Sessions (filter Account) | 2–3 |
| R4 Keep a client apart | Pools › New pool › for the project › sealed › Make (or the project's pool › seal) | 3–5 |
