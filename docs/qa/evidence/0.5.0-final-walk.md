**How the sizes were walked, honestly.** The native Dev window is 1701x1348 and cannot be resized (AX set-size returns 0 and nothing changes: W-03 again), and `lab_drive` has no wheel, no Page Down and no resize. So everything "at 1024x680 / 1280x800" below was measured on the **read-only bridge in the browser pane** (the same React UI; a viewport of exactly 1024x680 or 1280x800; dark theme; writes refused by the bridge, so those runs show layout and scrolling only). `lab-bridge` (the write mode) refuses to start in every lab because the lab's stand-in `AI_JUGGLER_CLAUDE_BIN` is set in the process, so the plain `bridge` command was used. Each dialog was measured by script: the dialog's rectangle against the viewport, every scroll container in it, and the header and action positions before and after scrolling its body to the end. The wheel was proven live on one surface with the browser tool's scroll (see H). Pointer-wheel and keyboard (Page Down, Tab below the fold) on the native app: **not possible with this kit.**
