# AJ-E1539 measured switch fidelity, 2026-10-28 (lab 19)

The tables `features::switch_fidelity` wrote for every hop of the live switching lab's final run, in a clean environment (lab 19 in [lab-2026-10-28.md](lab-2026-10-28.md)), unedited. Claude Code 2.1.310, codex-cli 0.163.0. "Lab A" and "Lab B" are two Claude Code accounts, "Lab Codex" the Mac's Codex home. Every count is in the source's own units, read through the adapters' own transcript readers.

How to read a row:
- **Source** is what the source held at switch time, **Carried** what the target got, **%** their ratio.
- "(by design)" marks a reduction the mechanism makes and says: a replay or an update gives each tool call as one line, not its result; another tool can't take over a subagent; an update gives older turns one line each.
- "(lost)" marks a loss.
- **Project notes** (D-51, from lab 21 on): the notes the source's tool keeps for this project, against those on the target or quoted in its handover. They travel only with the user's tick, so one that didn't arrive is "(by design)", never a loss.
- A fact's "In a file" says whether any project file holds it (a planted fact must not). "In what the target got" says whether the copy, the handover, or the original and its update holds it. "Probe" is how the target answered.
