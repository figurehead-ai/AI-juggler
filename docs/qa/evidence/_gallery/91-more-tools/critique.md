# 91-more-tools: adding accounts for more tools, the tool chooser and first run finding four setups

Design critique (D-57, AJ-E2814). First critique of this family, written at the 0.3.2 re-render from its captures as they are now.

## 0.3.2

add-account-chooser lists four installed tools (Claude Code, OpenCode, Kimi Code, Grok Build), each with a solid violet button; with 0.3.2's deeper fill these are four equal primaries in one small dialog, so nothing says which is the usual pick, and an outlined button per row would carry the same choice more quietly. The dialog itself lifts well off the blurred page in both themes. first-run-found is a well-ordered page: a four-step header, a large heading ("You already have 4 setups on this computer."), the setups grouped by tool with the installed version at the right of each group, then a colour dot, name, path, "Used yesterday" and a green "Signed in" per row, and two choice cards with "Use them where they are" marked Recommended and selected. At 1280 × 800 the capture ends at "Add a fresh account instead · Import from another folder…", so the page's primary button is below the fold on first run.

## Weak

- add-account-chooser-1280x800-dark.png, add-account-chooser-1280x800-light.png: four solid violet buttons, no single primary.
- first-run-found-1280x800-dark.png, first-run-found-1280x800-light.png: the button that brings the setups in is below the first screen.
