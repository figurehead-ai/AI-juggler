# 76-project-manage: project and session menus, forget, relocate, rename and pins

Design critique (D-57, AJ-E2814). First critique of this family, written at the 0.3.2 re-render from its captures as they are now.

## 0.3.2

project-actions and project-menu show the project menu with icons, grouped by rules, and a red Forget… last; forget-project's dialog is short and keeps Forget a quiet red outline. relocate puts a red "Project directory is missing" banner with Relocate… above the overview cards, which now stand off the canvas in both themes, but the Activity chart's date labels are cut by the card's bottom edge. session-menu, named for a session's row menu, shows the home page with no menu open, so the capture does not show its subject. project-menu captures the rail scrolled so far that the App / Project / Account switch is half cut under the top edge. settings-editor's theme, density and order choices are radio cards with the chosen one tinted, and rail-pins shows pinned projects cleanly. rename-session was not re-rendered this round and still shows the 0.3.1 colours (its pale Save in dark).

## Weak

- session-menu-1280x800 (both themes): no menu is open; the capture shows only the home page.
- relocate-1280x800 (both themes): the Activity chart's date labels are cut by the card's bottom edge.
- project-menu-1280x800 (both themes): the rail's App / Project / Account switch is half hidden under the top edge.
- project-actions, project-menu, session-menu: the rail row "Stopped with an error · 7…" loses its age.
