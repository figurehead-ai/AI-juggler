# Walk by hand — AI Juggler 0.0.11, 2026-10-21

Walked as a user would, the way the maintainer dogfoods a Beta: six
journeys, a screenshot per finding. Main at `513d6574` (0.0.11 + #94).

## Setup

- **Real app**: AI Juggler Dev, release build from this checkout
  (`just app`), started from the shell with a throwaway `HOME`: a
  `~/.claude` (settings.json, four project transcripts in two projects),
  `~/.claude.json`, one `ClaudeCodeProfiles/work` folder, and a `~/.codex`
  (config.toml, one rollout). `PATH` held only stand-in `claude` and
  `codex` scripts that print a line and sleep — nothing could sign in or
  reach a vendor. The real home, `~/.claude`, the real ClaudeCodeProfiles
  and the real AI Juggler data were never read or written.
- **What the real app could show here**: this Mac has no Accessibility
  or Screen Recording grant for the session (and none was asked for), so
  the real window could not be clicked or captured (`screencapture -l`
  → "could not create image from window"). The real app was used for what
  needs no clicks: starting on the fixture home, and journey 6.
- **The clicks**: the UI in the built-in browser (vite dev server, mock
  bridge) at 1280×800, dark, seeded per journey with the same seams the
  Playwright journeys use (`__AIJ_SCAN_REPORT__`,
  `__AIJ_PROVIDER_INSTALLS__`, `__AIJ_IMPORT_ERROR__`,
  `__AIJ_IMPORT_FAIL_PATHS__`, `__AIJ_GOING_BACK__`, the `allStatuses`
  fixture plus history-only projects). The scan seeded into the UI is
  the fixture home's setups.

### M1 — "CPU N%" means two things — for #85

- **Home's This Mac**: a row's "CPU 14%" is a share of one core, the way
  Activity Monitor counts it (its tooltip says "100% is one core busy").
  The AI-tools total is spelled out: "2% of all CPU cores".
- **The menu**: a tool's line ("Claude app · 6 windows · CPU 1% · …") uses
  `ToolTotalsInfo.cpu_pct`, a share of **all** cores, with the same bare
  "CPU N%" words. So the same Claude app can read "CPU 14%" on Home and
  "CPU 1%" in the menu. The Mac's own line ("CPU 27% · Memory …") is also
  a share of all cores.

### M2 — The alert's figure and the tool's figure disagree in one menu — for #85

- **Trace**: "Your Mac is under memory pressure — The Claude app is using
  about 4.9 GB" and, two lines below, "Claude app · 6 windows · CPU 1% ·
  about 12 GB".
- **Why**: the alert's subject is the single heaviest tree (one window),
  but it is worded as the whole app. The menu groups by tool. Home lists
  trees one by one, so there the two figures match.

### M3 — Small word differences from Home — for #85

- An unmeasured CPU reads "CPU unknown" in the menu and "CPU —" on Home.
- Memory and CPU come in the opposite order: Home puts memory first
  ("about 1.6 GB / CPU 14%"); the menu puts CPU first ("CPU 5% · about
  9.9 GB").
- With nothing running, the menu's first line says "Nothing running —
  your Mac has room" and the tool section then says "No AI tools running"
  as well.
