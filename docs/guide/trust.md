# What AI Juggler touches

AI Juggler sits next to your coding tools and your accounts, so you should know exactly what it reads, changes and sends. This page says it, and each line names the tests that check it. Those tests run on every change to AI Juggler, and a line whose tests are gone fails the build.

The same list is in the app: More › **Privacy**, and Settings › Privacy links to it.

## What it reads, on your Mac only

- It never reads the passwords, tokens or API keys your tools keep, or the tools' Keychain items. It reads only whether you're signed in, and as which account: its email and organisation.
  <sub>Checked by [`no_sign_in_file_is_read`](../../crates/juggler-app/tests/no_bare_tools.rs), [`login_state_is_metadata_only`](../../crates/juggler-adapters/tests/claude_code_adapter.rs), [`scan_code_never_reads_credential_contents`](../../crates/juggler-adapters/tests/scan.rs), [`the_environment_scan_runs_no_vendor_cli`](../../crates/juggler-app/tests/environment_scan_no_cli.rs), [`the_sign_in_probe_reads_kinds_never_values`](../../crates/juggler-adapters/tests/opencode_adapter.rs), [`the_sign_in_probe_reads_which_files_are_there_never_what_they_hold`](../../crates/juggler-adapters/tests/kimi_code_adapter.rs), [`the_sign_in_probe_reads_modes_never_values`](../../crates/juggler-adapters/tests/grok_build_adapter.rs).</sub>
- From Claude Code's settings.json it reads only the settings it needs, each one named in its code and checked.
  <sub>Checked by [`no_sign_in_file_is_read`](../../crates/juggler-app/tests/no_bare_tools.rs).</sub>
- With crash reports on, it looks through macOS's new crash reports for AI Juggler's own, and keeps only what failed and where.
  <sub>Checked by [`an_ips_crash_keeps_its_kind_and_frames_and_nothing_else`](../../crates/juggler-app/src/crash_native.rs), [`only_crashes_after_the_first_look_are_kept_and_never_reads_nothing`](../../crates/juggler-app/src/crash_native.rs), [`links_and_oversized_files_are_not_read`](../../crates/juggler-app/src/crash_native.rs).</sub>
- If you use Claude Squad or Vibe Kanban, it reads their own lists for which repository each of their worktrees belongs to and which config folders their profiles use, and nothing else they keep. It never opens their sign-in or key files.
  <sub>Checked by [`claude_squad_worktrees_come_with_their_repositories`](../../crates/juggler-adapters/tests/other_managers.rs), [`vibe_kanban_profiles_offer_the_folders_they_point_at`](../../crates/juggler-adapters/tests/other_managers.rs), [`the_importers_never_name_a_sign_in_or_key_file`](../../crates/juggler-adapters/tests/other_managers.rs).</sub>
- To show what's open, it reads each tool's own session files: Claude Code's list of running sessions, and from the Claude app only each session's ids, folder, title, times, archived mark and status word, never its summaries. For the Codex app it reads which of its files the app has open. It never reads a running program's environment, where the Claude app keeps a sign-in token.
  <sub>Checked by [`no_process_environment_is_ever_read`](../../crates/juggler-app/tests/trust.rs), [`the_process_read_never_asks_for_environments`](../../crates/juggler-app/src/features/conversations/procs.rs), [`an_app_session_keeps_its_status_word_and_never_its_summary_text`](../../crates/juggler-adapters/src/claude_live.rs), [`a_pid_file_reads_its_session_and_the_key_file_is_never_listed`](../../crates/juggler-adapters/src/claude_live.rs), [`held_locks_and_rollouts_name_their_threads_once`](../../crates/juggler-adapters/src/codex_live.rs).</sub>
- For a Claude account's limits in sessions it didn't start, it reads three of Claude's own records, on your Mac: the Claude app's plan-usage-history.json (percent used and when), the limit-hit lines in Claude Code's transcripts (which limit and when it resets, never the message) and cachedUsageUtilization in Claude Code's .claude.json (percent used and resets). It keeps no other field and logs none of it.
  <sub>Checked by [`nothing_but_the_ids_and_the_numbers_is_kept`](../../crates/juggler-adapters/src/claude_limits/tests.rs), [`a_transcripts_hits_are_read_line_by_line_and_its_words_never_kept`](../../crates/juggler-adapters/src/claude_limits/tests.rs), [`two_accounts_of_one_org_in_one_instance_make_its_samples_nobodys`](../../crates/juggler-adapters/src/claude_limits/tests.rs), [`the_limit_readers_log_nothing`](../../crates/juggler-adapters/src/claude_limits/tests.rs).</sub>
- When a Claude profile's limit reading is old and the profile is in use, AI Juggler runs Claude Code's own usage check there (claude -p /usage, with hooks off), at most every 15 minutes. Claude Code asks Anthropic with its own sign-in, as /usage does: no message goes to Claude, AI Juggler sends nothing, never sees the sign-in and keeps no output. Each profile's page turns it off.
  <sub>Checked by [`once_ruled_on_the_probe_runs_claude_codes_usage_in_the_profile_and_keeps_no_output`](../../crates/juggler-app/tests/claude_limits_records.rs), [`asking_claude_code_is_on_by_default_and_off_everywhere_when_turned_off`](../../crates/juggler-app/tests/claude_limits_records.rs).</sub>
- To know which app and profile a session runs in, it reads the names of running programs, the apps that started them and the options they started with, on your Mac only, and never their environment.
  <sub>Checked by [`a_desktop_session_is_in_its_claude_instance_by_its_argument`](../../crates/juggler-app/src/features/conversations/places.rs), [`a_terminal_session_is_in_its_terminal_and_an_unknown_app_by_its_name`](../../crates/juggler-app/src/features/conversations/places.rs), [`no_process_environment_is_ever_read`](../../crates/juggler-app/tests/trust.rs).</sub>
- To show apps' icons, AI Juggler reads the icon from each app installed on your Mac; nothing is sent or copied elsewhere. It reads only inside the app itself, and keeps a small copy in its own folder until the app changes.
  <sub>Checked by [`only_an_app_folder_that_is_not_a_link_is_read`](../../crates/juggler-app/src/features/app_icons/tests.rs), [`a_bundle_whose_icon_or_plist_links_out_of_it_is_refused`](../../crates/juggler-app/src/features/app_icons/tests.rs), [`an_app_is_found_by_its_place_its_id_or_its_folder_and_never_otherwise`](../../crates/juggler-app/src/features/app_icons/tests.rs), [`an_icon_is_kept_until_the_app_changes_then_read_again`](../../crates/juggler-app/src/features/app_icons/tests.rs), [`the_app_reaches_only_its_own_addresses`](../../crates/juggler-app/tests/trust.rs).</sub>
- To show what else is using memory, This Mac names the biggest other apps, and Processes lists the rest of your Mac when you include other apps: by app or program name, with their memory. It never shows their folders or the options they started with, and it can't stop them.
  <sub>Checked by [`other_apps_show_names_never_paths`](../../crates/juggler-app/src/machine_memory.rs), [`other_processes_carry_a_name_and_memory_only_and_leave_ai_juggler_out`](../../crates/juggler-supervisor/src/live_stats.rs), [`shows the whole Mac's memory, explains pressure, and lists what else uses it by name, read-only`](../../ui/src/screens/this-mac-page.test.tsx), [`the_rest_of_the_mac_shows_only_when_asked_for_and_only_names_and_memory`](../../crates/juggler-app/tests/processes_graph.rs), [`Include other apps adds the rest of this Mac: names and memory only, nothing to stop`](../../ui/src/screens/processes-page.test.tsx), [`no_process_environment_is_ever_read`](../../crates/juggler-app/tests/trust.rs).</sub>
- A session's last messages are read from the end of its transcript on your Mac while its page is open, and kept nowhere. One switch in Settings › Desktop apps turns them off.
  <sub>Checked by [`Last messages are on until you turn them off, and only off is kept`](../../ui/src/screens/settings/desktop-apps.test.tsx), [`are read only once the page is shown, and once`](../../ui/src/pages/session/last-messages.test.tsx), [`a paired Mac's session is never read here`](../../ui/src/pages/session/last-messages.test.tsx), [`only_the_end_is_read_and_a_cut_line_is_skipped`](../../crates/juggler-adapters/src/last_turns.rs), [`an_api_key_in_a_turn_shows_redacted`](../../crates/juggler-app/src/features/conversations/last_messages.rs), [`a_private_key_block_is_taken_out_whole`](../../crates/juggler-app/src/features/conversations/last_messages.rs), [`nothing_is_kept_written_or_logged`](../../crates/juggler-app/src/features/conversations/last_messages.rs), [`off_in_settings_no_transcript_is_looked_up_or_read`](../../crates/juggler-app/src/features/conversations/last_messages.rs).</sub>
- For a session it runs without a terminal, what the page shows comes from the tool as it works. AI Juggler holds only the latest part, in memory, and never writes it down; the tool keeps its own transcript as it always does.
  <sub>Checked by [`the_conversation_is_held_in_memory_and_bounded`](../../crates/juggler-app/src/features/runtime/driver.rs), [`a_driven_session_is_exact_and_answered_only_by_the_user`](../../crates/juggler-app/tests/runtime.rs).</sub>
- For sessions other apps run, it keeps each of their processes' program name, start time, the session it was in and a hash of its command line, on your Mac only, for 7 days, so a process left behind can be named by its session. Never its environment, and never the command line itself.
  <sub>Checked by [`a_sighting_never_holds_the_environment_or_the_command_line`](../../crates/juggler-core/tests/sightings_storage.rs), [`a_sighting_is_forgotten_seven_days_after_it_was_last_seen`](../../crates/juggler-core/tests/sightings_storage.rs), [`the_hash_is_keyed_and_never_the_line`](../../crates/juggler-app/src/features/processes/sightings.rs).</sub>

## What it changes

- What it keeps lives in its own folder, ~/Library/Application Support/AI Juggler (AI Juggler Nightly for Nightly), and in its own Keychain items.
  <sub>Checked by [`ai_juggler_keeps_its_existing_folder_keychain_items_and_port`](../../crates/juggler-app/src/edition.rs).</sub>
- With Search the words of every session on, its index holds the words to search, not the conversations, in its own folder; turning it off deletes the index.
  <sub>Checked by [`turning_it_off_leaves_no_index_behind`](../../crates/juggler-app/tests/outside_search.rs), [`a_search_index_file_is_the_same_index_and_removes_whole`](../../crates/juggler-core/src/storage/transcript_index.rs).</sub>
- It never writes to a setup you use where it is, unless you turn on a change that says so first.
  <sub>Checked by [`a_setup_used_where_it_is_is_never_written_by_ai_juggler`](../../crates/juggler-app/tests/in_place_accounts.rs), [`a_codex_home_used_where_it_is_is_never_written_by_ai_juggler`](../../crates/juggler-app/tests/codex_in_place.rs), [`the_default_folder_is_used_where_it_is_and_never_written`](../../crates/juggler-app/tests/opencode_provider.rs), [`the_default_home_is_used_where_it_is_and_never_written`](../../crates/juggler-app/tests/kimi_provider.rs), [`its_sessions_become_projects_and_its_default_home_is_never_written`](../../crates/juggler-app/tests/grok_provider.rs).</sub>
- It changes your setups and projects only when you apply a change, shows it first, and can undo it.
  <sub>Checked by [`turning_it_on_changes_only_the_status_line_and_off_puts_every_byte_back`](../../crates/juggler-app/tests/outside_capture.rs), [`nothing_is_written_until_the_user_applies`](../../crates/juggler-app/tests/project_sync.rs), [`the_other_claude_account_is_offered_what_it_lacks_and_gets_only_what_is_picked`](../../crates/juggler-app/tests/switch_setup.rs), [`a_new_account_gets_the_usual_settings_and_never_a_credential_history_or_cache`](../../crates/juggler-app/tests/account_settings.rs).</sub>
- Copying settings or MCP servers never takes a secret along: the copy names it, and you provide it.
  <sub>Checked by [`a_setting_with_a_secret_written_in_it_is_never_copied_or_recorded`](../../crates/juggler-app/tests/account_settings.rs), [`a_server_is_copied_across_tools_without_its_secret_and_undone`](../../crates/juggler-app/tests/project_sync.rs), [`the_other_claude_account_is_offered_what_it_lacks_and_gets_only_what_is_picked`](../../crates/juggler-app/tests/switch_setup.rs), [`a_settings_file_with_a_key_written_in_it_stays_behind_named`](../../crates/juggler-adapters/tests/opencode_adapter.rs), [`a_copy_keeps_settings_but_never_a_sign_in_a_key_or_the_sessions`](../../crates/juggler-adapters/tests/kimi_code_adapter.rs), [`a_copy_keeps_settings_and_sessions_but_never_a_sign_in_or_a_key`](../../crates/juggler-adapters/tests/grok_build_adapter.rs).</sub>
- The key you paste for an account added through another service, such as OpenCode Go or Kimi, is kept in AI Juggler's own Keychain item. Only that account's sessions get it, when they start, in the setting their tool reads. It's never written to a file, a log, the search index or a backup, never shown again, and removing the account removes it.
  <sub>Checked by [`an_account_through_another_service_keeps_its_key_only_in_the_keychain`](../../crates/juggler-app/tests/service_accounts.rs), [`the_key_reaches_only_that_accounts_launch_and_never_its_arguments`](../../crates/juggler-app/tests/service_accounts.rs), [`every_session_starts_through_the_one_spawn_path`](../../crates/juggler-app/tests/service_accounts.rs), [`removing_the_last_profile_removes_the_key`](../../crates/juggler-app/tests/service_accounts.rs), [`a_service_accounts_key_never_reaches_a_backup`](../../crates/juggler-app/tests/backup_restore.rs), [`editions_share_nothing`](../../crates/juggler-app/src/edition.rs).</sub>
- Once you say yes, sessions it starts get its agent tools, added to that launch only and never written into your setup: who they are, who's in their pool, what each says it's doing, their own status line, messages and shared documents with their pool, and the pool's tasks. You can switch them off for a project or a profile.
  <sub>Checked by [`nothing_is_added_before_the_question_is_answered`](../../crates/juggler-agentbridge/tests/bridge.rs), [`the_key_is_in_the_environment_only_and_nothing_lands_in_the_account_folder`](../../crates/juggler-agentbridge/tests/bridge.rs), [`adds_the_agent_bridge_honestly`](../../crates/juggler-adapters/tests/conformance/mod.rs).</sub>

It sees each account by the name you gave it, never an email or a plan, and only through a connection no one but you on this Mac can open.
  <sub>Checked by [`each_level_refuses_what_it_doesnt_allow_and_every_call_is_audited`](../../crates/juggler-agentbridge/tests/bridge.rs), [`agents_see_account_labels_never_emails_or_plans`](../../crates/juggler-agentbridge/tests/bridge.rs), [`the_socket_is_0600_in_a_0700_folder_and_answers_only_current_keys`](../../crates/juggler-agentbridge/tests/bridge.rs), [`the_task_commands_go_through_the_real_binary_and_the_level`](../../crates/juggler-agentbridge/tests/bridge.rs).</sub>

A message waits in its recipient's inbox; it goes into a session as its next prompt only when you click Deliver, or the pool is at Full or you made a rule, and then only between turns, never at a tool's own question or while you type. A session in a terminal is never typed into. Every message says who sent it and that it can't approve anything or change settings.
  <sub>Checked by [`delivery_waits_for_the_users_click_at_work_together`](../../crates/juggler-app/tests/messages.rs), [`at_full_it_goes_in_between_turns_never_at_a_permission_prompt_or_over_typing`](../../crates/juggler-app/tests/messages.rs), [`a_message_reaches_a_sessions_input_only_through_its_turn_and_only_with_permission`](../../crates/juggler-app/tests/messages_guardrails.rs), [`provenance_is_on_every_message_an_agent_reads_and_every_delivery`](../../crates/juggler-app/tests/messages_guardrails.rs).</sub>

  <sub>Checked by [`shared_docs_are_redacted_content_addressed_and_only_the_pools`](../../crates/juggler-app/tests/messages.rs), [`a_ping_pong_between_two_fake_agents_stops_at_the_cap`](../../crates/juggler-app/tests/messages.rs), [`nothing_about_messages_leaves_the_mac`](../../crates/juggler-app/tests/messages_guardrails.rs).</sub>
- A pool's agents can add tasks, take a ready one and say where it is, and only one session gets a task.   <sub>Checked by [`n_fake_agents_claim_one_task_and_exactly_one_wins`](../../crates/juggler-app/tests/tasks.rs), [`each_level_decides_and_a_change_above_it_waits_on_the_user`](../../crates/juggler-app/tests/tasks.rs), [`no_agent_starts_a_session_or_picks_an_account`](../../crates/juggler-app/tests/tasks_guardrails.rs), [`assignment_never_reads_quota`](../../crates/juggler-app/tests/tasks_guardrails.rs).</sub>
- Tasks stay in AI Juggler's own data on this Mac, with every change in a history that can't be rewritten. A task's words are its writer's and change nothing. The title and state of a GitHub issue a task links to are looked up only when you click, by GitHub's own command line with your own sign-in there. Nothing about tasks goes over Fleet.
  <sub>Checked by [`a_claim_takes_a_ready_task_once`](../../crates/juggler-core/src/storage/tasks.rs), [`a_tasks_words_are_data_and_change_nothing`](../../crates/juggler-app/tests/tasks_guardrails.rs), [`the_issue_is_looked_up_only_on_a_click_and_offline_says_so`](../../crates/juggler-app/tests/tasks.rs), [`nothing_about_tasks_leaves_the_mac`](../../crates/juggler-app/tests/tasks_guardrails.rs).</sub>

Nothing is written into your setup. Running Claude Code without a terminal is a Beta you pick for one session at a time.

  <sub>Checked by [`no_automatic_rule_ever_stops_another_apps_leftover`](../../crates/juggler-app/tests/observed_stop.rs), [`every_refusal_sends_zero_signals`](../../crates/juggler-app/tests/observed_stop.rs), [`a_verified_leftover_of_an_ended_session_stops_and_is_audited`](../../crates/juggler-app/tests/observed_stop.rs), [`the_identity_check_fails_closed_on_every_leg`](../../crates/juggler-app/src/features/processes/stop.rs).</sub>

## What it sends

- It makes no requests to Anthropic, OpenAI or any other AI provider. Your tools talk to their providers themselves.
  <sub>Checked by [`only_the_listed_crates_can_reach_the_network`](../../crates/juggler-app/tests/trust.rs), [`the_app_reaches_only_its_own_addresses`](../../crates/juggler-app/tests/trust.rs), [`the_window_can_reach_nothing_but_the_app`](../../crates/juggler-app/tests/trust.rs), [`no_http_client_anywhere_in_the_adapters_crate`](../../crates/juggler-adapters/tests/quota_ingest.rs).</sub>
- It never sits between your tools and their providers: it sets no proxy for them. It sets a provider address only for an account you add through another service, and only the address that service publishes.
  <sub>Checked by [`ai_juggler_never_points_a_tool_at_another_address`](../../crates/juggler-app/tests/trust.rs), [`a_provider_address_is_only_ever_one_a_service_publishes`](../../crates/juggler-app/tests/trust.rs).</sub>
- It checks GitHub for updates when it starts, if that's on, or when you choose Check now.
  <sub>Checked by [`check_off_means_zero_connections_and_on_reaches_the_feed`](../../crates/juggler-app/tests/updates_plugin.rs), [`the_app_reaches_only_its_own_addresses`](../../crates/juggler-app/tests/trust.rs).</sub>
- Once a day, if that's on, it asks npm's public registry for the newest version of each tool you have an account on, and shows it on that tool's page. It never updates a tool for you.
  <sub>Checked by [`one_request_per_tool_a_day_only_for_tools_in_use_and_none_when_off`](../../crates/juggler-app/tests/tool_updates.rs), [`no_update_is_ever_run`](../../crates/juggler-app/src/features/tool_updates/mod.rs), [`the_app_reaches_only_its_own_addresses`](../../crates/juggler-app/tests/trust.rs).</sub>
- Usage statistics are off until you choose. When on, they go to stats.figurehead.ai as counts only: never your words, files, paths or names.
  <sub>Checked by [`without_a_choice_nothing_is_created_and_nothing_is_sent`](../../crates/juggler-app/tests/stats_guardrails.rs), [`nothing_the_user_owns_reaches_the_stats_store_or_a_report`](../../crates/juggler-app/tests/stats_guardrails.rs), [`off_creates_no_folder_and_records_nothing`](../../crates/juggler-stats/src/tests.rs), [`the_app_reaches_only_its_own_addresses`](../../crates/juggler-app/tests/trust.rs).</sub>
- Crash reports are kept on your Mac, with names and paths taken out. This version has nowhere to send them.
  <sub>Checked by [`a_seeded_crash_is_scrubbed_before_it_is_kept`](../../crates/juggler-app/src/crash.rs), [`crash_reports_have_nowhere_to_go`](../../crates/juggler-app/tests/trust.rs), [`the_crash_sender_is_built_only_with_an_address`](../../crates/juggler-app/tests/trust.rs).</sub>
- The Figurehead account is optional. Signed out, nothing goes to it; signed in, a feature you've turned off sends nothing.
  <sub>Checked by [`g1_signed_out_is_silent`](../../crates/juggler-app/tests/cloud_guardrails.rs), [`g2_a_feature_that_is_off_never_calls_its_endpoint`](../../crates/juggler-app/tests/cloud_guardrails.rs).</sub>
- Fleet connects only Macs you paired, directly and encrypted, each checking the other's key, and no server carries the traffic. To be found, a Mac announces itself on your local network, and in your Figurehead account if you turn that on.
